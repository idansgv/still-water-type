# Meltdown

**Status:** removed on 5 October 2026 (a draft, briefly live in Release 1, that Idan judged below the bar). Code: git history, last at commit `e09f0ad` (`src/posters/meltdown.js`).

**Concept.** "MELT / DOWN" in crisp type that melts: design and technology at the point where both give way.

**Underneath.** A heat field plus a shader that finds the nearest letter upstream along gravity and pours it as round-tipped drips.

**Interactions.** Hold or drag to melt; it re-solidifies.

**Why it went.** Idan's verdict was that the stock drips looked like an effect applied to type rather than a material the type lives in, far from Still Water's elegance.

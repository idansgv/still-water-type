# Flat

**Status:** retired in the first round of portfolio posters (never published). The code was replaced by Emboss and is in early git history.

**Concept.** The word FLAT ray-marched as a solid slab: a bold flat word that is really extruded 3D, orbit to see it.

**Why it went.** The generic extrusion looked like a stock effect; the top face magnified and the framing overflowed. Its idea (type that is secretly extruded geometry) returned, much better, as Collapse and Explode.
